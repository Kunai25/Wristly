# Wristly: AI-Powered Ergonomic Wrist Monitoring System

Wristly is an AI-powered ergonomic wrist monitoring system designed to prevent Carpal Tunnel Syndrome (CTS). This project is developed for **NGN Hacks 2026** with a focus on modular, production-quality engineering.

---

## 1. Project Overview
Carpal Tunnel Syndrome (CTS) is a highly prevalent repetitive strain injury. Wristly addresses this by continuously tracking wrist posture (pitch, roll, and simulated heading) using hardware sensors, analyzing movement patterns in real-time, and leveraging Featherless AI to provide personalized ergonomic recommendations.
